# Kaizen Concepts Customer Website

Static customer-facing catalogue website for **Kaizen Concepts LLC**, built from the supplied customer furniture catalogue and matched product images from the supplied updated stocklist.

## Included
- 127 catalogue products with model numbers, categories, finishes and descriptions.
- Matched high-resolution product images from the supplied stocklist.
- No prices or stock quantities displayed.
- Product detail pop-ups.
- Product-specific WhatsApp enquiry buttons.
- General WhatsApp, email and phone contact buttons.
- Full customer catalogue PDF.
- Responsive mobile layout.
- No database, paid software, or backend required.

## Free hosting
This is a plain HTML/CSS/JavaScript site and can be hosted free on GitHub Pages or Cloudflare Pages while keeping your domain registered with GoDaddy.
